General REST API

Send client activity to the Radar using a secure API key

Example payload
{
  "client_id": "northstar-retail",
  "source": "crm",
  "event_type": "meeting",
  "occurred_at": "2025-03-14T10:30:00Z",
  "summary": "Quarterly strategy review",
  "sentiment": "neutral",
  "value": 24000
}

Authentication: Authorization: Bearer YOUR_API_KEY. Events are scored after validation and deduplication.
